# KindleModShelf

A community resource for Kindle mods, guides, games, utilities, and customizations — jailbreak instructions, e-ink apps, and advanced tweaks, all in one place.

Visit the site: [kindlemodshelf.me](https://kindlemodshelf.me)

---

## Creating or Editing Pages

Use the [Page Builder](https://kindlemodshelf.me/pagebuilder.html) for regular pages, including editing pages that already exist. Skip it only for custom pages with special layout, gallery, or app logic.

It's a markdown editor: write in markdown with a live preview, browse and load any existing page to edit it, generate a homepage card, and export a `.md` file when done.

## Sharing Your Page

1. Fork the repo
2. Add your exported `.md` file to `public/content/`
3. New page? Add its homepage card to `index.html`
4. Open a pull request

Pull requests are the only way to submit pages.

## Issues & Feedback

Always open a [GitHub issue](../../issues) — bugs, ideas, new pages, corrections, all of it.
