# Archived

:::warning
**These projects are no longer maintained.** Some repositories are archived (read-only) and some have been removed or moved, so links may be dead. They may still work on older firmware, but expect no fixes or support. Newer alternatives are listed where one exists. To install apps today, use KPM, which modern jailbreaks pre-install; see the [wiki guide](https://kindlemodding.org/jailbreaking/whats-next/installing-homebrew.html).
:::

## KindleForge

On-device app store for installing Kindle mods without manual USB file copying. The repository is archived.

  - **Repository:** [KindleForge on GitHub](https://github.com/KindleTweaks/KindleForge)
  - **Organization:** [KindleTweaks on GitHub](https://github.com/KindleTweaks)
  - **Releases:** [KindleForge.zip](https://github.com/KindleTweaks/KindleForge/releases)

## PEKI (Penguins' Epic KUAL Installer)

Installs and launches KUAL without MRPI and adds a polished booklet icon. The repository is archived.

  - **Repository:** [PEKI on GitHub](https://github.com/KindleTweaks/PEKI)
  - **Organization:** [KindleTweaks on GitHub](https://github.com/KindleTweaks)
  - **Releases:** [PEKI releases](https://github.com/KindleTweaks/PEKI/releases)

## HotfixUpdater

On-device scriptlet that updates your Kindle hotfix without a computer. It is no longer maintained.

  - **Repository:** [HotfixUpdater on GitHub](https://github.com/KindleTweaks/HotfixUpdater)
  - **Organization:** [KindleTweaks on GitHub](https://github.com/KindleTweaks)

## GNU Nano (HF)

A terminal text editor for hard-float Kindles. It is no longer maintained.

  - **Discussion:** [Kindle Modding Community thread](https://discord.com/channels/1083603487025274911/1112794488700686506/threads/1418538699775283310)

## Kindle BT Keepalive

Background utility that keeps Bluetooth active so your headphones stay connected while you read. The repository is no longer available.

## Archived KOReader Plugins

These plugins were on the plugins list. Their repositories are now archived (read-only). For wireless file management, see ZenFM on the plugins list.

  - [File Browser](https://github.com/b-/filebrowser.koplugin): Manage Kindle files from a browser web UI.
  - [File Browser Plus](https://github.com/patelneeraj/filebrowserplus.koplugin): Runs a Filebrowser server for wireless file management.
  - [KoInsight](https://github.com/Ko-Insight/KoInsight): Web dashboard for reading stats, streaks and history.

## mip-wiki

The mip-wiki guides are archived and no longer updated. The site is still online, but the information may be out of date. Current tools and package listings are in the [KindleTweaks GitHub organization](https://github.com/KindleTweaks).

  - [Repair Guide](https://mip-wiki.pages.dev/database/unbrick/): Figure out if your Kindle is actually bricked, then work through the recovery steps.
  - [Application Error Popup](https://mip-wiki.pages.dev/database/applicationerror/): It looks alarming, but the actual cause is pretty mundane.
  - [Checking OTA Status](https://mip-wiki.pages.dev/database/otastatus/): Getting OTA blocking right is one of the most critical parts of jailbreaking — confirm it actually took.
  - [Disabling Crash Logs](https://mip-wiki.pages.dev/database/crashlog/): Seeing odd files like "KPPMainApp" or "Mesquite" show up on your home screen? Here's what causes that and how to make it stop.
  - [Filling Storage to Prevent Updates](https://mip-wiki.pages.dev/database/fillingstorage/): Keep automatic firmware updates from closing your jailbreak window by topping off the Kindle's storage first.
  - [Installing and Using USBNet(Lite)](https://mip-wiki.pages.dev/database/usbnet/): Control your Kindle over Wi-Fi instead of USB — install apps and move files wirelessly.
  - [Installing KUAL with PEKI](https://mip-wiki.pages.dev/database/peki/): PEKI has taken over from MRPI as the go-to way to install KUAL, with fewer hiccups and broader compatibility.
  - [KindleForge App Store](https://mip-wiki.pages.dev/database/kforge/): A rundown of the KindleForge app store, where you can grab KUAL, KOReader, an OTA checker, Alpine Linux, and other apps.
  - [Preserve Files on Deregister](https://mip-wiki.pages.dev/database/preservefilesonderegister/): Move to a different Amazon account without wiping your jailbreak files — handy if jailbreaking forced a re-registration.
  - [Scriptlets and How to Use Them](https://mip-wiki.pages.dev/database/scriptlets/): One of the most popular methods for running apps on a Kindle — an explainer on what scriptlets are and how to use them.
  - [Toggling Bluetooth](https://mip-wiki.pages.dev/database/bluetooth/): Turn on Bluetooth functionality for Kindle units sold in regions without Audible support.
