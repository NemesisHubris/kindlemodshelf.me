# KindleHub Pro

> A website that turns the Kindle's browser into a whole device — 98 games, 60+ apps, a free book library and encrypted chat. Nothing to install.

## Access

  - [**kindlehub.pro**](https://kindlehub.pro) — No installation needed, open in your Kindle browser

## Features

  - **KindleOS launcher** \- A home screen with app folders, widgets, a lock screen and a control centre, or plain tabs if you prefer
  - **98 games** \- Every one turn-based or tap-driven, so the screen only repaints when you act
  - **Free book library** \- Search Project Gutenberg and read the full text in-page, with your position saved
  - **60+ apps** \- Notes, journal, flashcards with spaced repetition, calendar, spreadsheet, drawing, RSS reader, weather, maps, star map, dictionary, unit converter and more
  - **Encrypted chat and mail** \- End-to-end encrypted messaging between KindleHub users
  - **App store** \- Install the built-in apps you want, or write your own HTML app and publish it
  - **Bedside dashboard** \- A full-screen clock with watch faces, weather, timers and a light-based alarm
  - **Works offline** \- After the first visit the app is cached, so it opens without a connection
  - **Optional account** \- Encrypted cloud sync keeps notes, books and game progress across devices
  - **Free** \- Every app and every game is free

## How to Use

  1. Open your Kindle's web browser (Experimental Browser on older models)
  2. Go to **https://kindlehub.pro**
  3. Let the first load finish — the app caches itself, so later visits are much quicker
  4. Choose a look from the home screen: Classic tabs, the KindleOS launcher, or Retro
  5. Optionally create an account in Settings to sync your data across devices

## Notes

  - Built for e-ink: monochrome-safe contrast, large touch targets, and no animation loops
  - Ships its own on-screen keyboard, for Kindles where the native one is awkward in the browser
  - An account is optional — everything works signed out and stored on the device
  - Not a jailbreak and not a sideload; it is a web page, so nothing on the device is modified
